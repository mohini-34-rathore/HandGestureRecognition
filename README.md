# Hand Gesture Recognition

This project uses computer vision and deep learning to recognize hand gestures using live video feed and pre-trained models.

## 📁 Files

- `automatic.ipynb`: Automates the process of capturing and storing gesture data.
- `datacollection.ipynb`: Collects hand gesture data using webcam.
- `gesture.prediction.ipynb`: Predicts the hand gesture using a trained model.
- `train.h5.ipynb`: Trains the model and saves it as `train.h5`.

## 🛠️ Setup

1. Clone the repository:
```bash
git clone https://github.com/your-username/HandGestureRecognition.git
cd HandGestureRecognition
```

2. Install dependencies:
```bash
pip install -r requirements.txt
```

## 🧠 Libraries Used

- OpenCV
- TensorFlow / Keras
- NumPy
- Matplotlib

## 📸 Usage

Run the notebooks in the order:

1. `datacollection.ipynb`
2. `train.h5.ipynb`
3. `gesture.prediction.ipynb`

## 🤖 Future Work

- Add real-time gesture recognition app
- Improve model accuracy with more data
```
